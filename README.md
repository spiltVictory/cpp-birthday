# 小小程序员 · 生日祝福页

给 8–13 岁 C++ 学员做的生日祝福网站，外加一个老师用的生成页。

- **学生页 `index.html`**：手机优先、单文件、无外部依赖；打开就是孩子自己的生日页面。
- **老师页 `teacher.html`**：填姓名、生日、当前阶段、寄语，生成专属链接，复制发给家长。

页面把「生日」和「C++ 课程」串在一起：运行一段生日代码、吹蜡烛、点亮 L1–L12 技能树、读老师的信。

---

## 30 秒用起来

1. 浏览器打开 `teacher.html`。
2. 填学生姓名、生日，选当前阶段（寄语有默认，可改）。
3. 点 **复制专属链接**，发给家长。

学生打开链接就是自己的页面，不需要登录，也不需要安装任何东西。

> 本地直接打开 `teacher.html` 时，生成的是 `file://` 链接，只能在本机打开；部署到网上后会自动变成正式网址。部署见 [DEPLOY.md](DEPLOY.md)。

## 两个页面分别做什么

### 学生页 `index.html`

- 首屏：姓名、生日日期、当前阶段，以及一段 C++ 问候代码。
- **运行生日程序**：代码逐字打出，点运行后终端输出姓名、当前阶段颗 ★、ASCII 蛋糕和 `exit code 0`。
- **吹蜡烛**：点灭 5 根蜡烛，出现「愿望已写入内存」。
- **C++ 技能树**：L1–L12 来自趣味 C++ 大纲，当前阶段高亮「正在学」，前面显示「已学」，后面显示「未解锁」，每关可展开看 4 节课。
- **三行代码祝福 + 老师的信**：寄语和署名来自链接参数。
- 生日歌、彩带、星光；右上角可静音。

### 老师页 `teacher.html`

- 学生姓名（必填）
- 生日（孩子过生日的那一天，只显示日期，不计算年龄）
- 目前学习阶段（L1–L12，带关卡名）
- 寄语（默认已填，可改，可恢复默认）
- 署名（默认「你的 C++ 课导老师」）
- 实时预览、生成链接、复制、打开预览、下一位同学

生成页只在浏览器里拼链接，不保存、不上传学生信息。

## 给不同学生复用

1. 打开部署后的 `https://<你的用户名>.github.io/cpp-birthday/teacher.html`。
2. 改姓名 / 生日 / 阶段 → **复制专属链接** → 发给家长。
3. 点 **下一位同学**，姓名清空，继续下一位。

每位同学的链接大概长这样：

```
https://<你的用户名>.github.io/cpp-birthday/index.html?name=李小明&level=7&bday=2026-06-01&teacher=王老师
```

链接里带学生姓名，只发给对应家长，不要发群；也不要把学生名单提交到仓库。

## URL 参数

| 参数 | 作用 | 示例 / 默认 |
| --- | --- | --- |
| `name` | 学生姓名 | 最多 12 字，默认「小核桃」 |
| `bday` | 生日日期 | `2026-06-01`；不填则显示 `HBD` / 「你的生日」 |
| `level` | 当前 C++ 阶段 | 1–12，默认 4 |
| `teacher` | 署名 | 最多 16 字，默认「你的 C++ 课导老师」 |
| `msg` | 自定义寄语 | 最多 120 字，不填用默认寄语 |

示例：

```
index.html?name=李小明&level=7&bday=2026-06-01&teacher=王老师
```

姓名里的英文引号、反斜杠、尖括号会被自动去掉。

## 改默认内容

### 学生页 `index.html`

打开文件，找到 `<script>` 顶部的 `CONFIG`：

```js
const CONFIG = {
  name: "小核桃",
  bday: "",            // 默认不显示日期；老师页生成的链接会带 bday
  level: 4,
  teacher: "你的 C++ 课导老师",
  message: "今天不用写代码，只要负责开心。……",
  wishes: [ ... ]      // 三行代码祝福
};
```

- `wishes` 里每一条有 `code` 和 `note`，改文字即可。
- 页面上的中文文案直接搜索修改。
- 主题色在 `<style>` 顶部 `:root` 的 `--orange`、`--yellow`、`--mint` 等变量。
- 12 关课程在 `LEVELS` 里，每关 4 节课，带「实操 / 硬件 / 项目」标签。

### 老师页 `teacher.html`

- 默认寄语、默认署名：`DEFAULT_MSG`、`DEFAULT_TEACHER`
- 12 关名称：`LEVELS`（只需标题，和 `index.html` 保持一致）
- 页面文案和颜色与上面类似。

### 快速改单个学生

也可以直接用网址参数，或者打开部署后的学生页，点右上角 **✎** 临时改姓名、生日、阶段、寄语，再保存/复制链接。老师页更适合连续给多位同学做。

## 部署（GitHub Pages，免费）

完整步骤、push 命令、Pages 设置和常见问题都在 **[DEPLOY.md](DEPLOY.md)**。

简要版：

1. GitHub 新建空仓库 `cpp-birthday`（Public）。
2. 本目录已经 `git init` 并提交过一次，添加远程仓库后 push。
3. 仓库 Settings → Pages → 分支 `main`、目录 `/ (root)` → Save。
4. 1–2 分钟后得到 `https://<你的用户名>.github.io/cpp-birthday/`。

以后 `git push` 自动更新。`github.io` 在国内不同地区速度有差异；如果家长反馈打不开，可以绑定自己的域名，或换国内静态托管。

## 兼容性 & 注意

- 适配微信内置浏览器、iOS Safari、Android Chrome；桌面浏览器也能看。
- 单文件、无外部字体 / 图片 / JS 依赖；断网也能打开。
- 生日只显示日期，不计算年龄；终端里的 ★ 数量等于当前阶段 L1–L12。
- 声音和剪贴板都需要用户点击后才能使用，这是浏览器的限制。
- 开启「减少动态效果」的设备会自动跳过打字、彩带和大部分动画。
- 页面里的「核桃编程 · 信奥科技特长生班」只作为班级标识，不是官方课程页。
- 老师寄语中涉及的承诺（奖励、返场、礼物等）请按实际情况写。
